Number Guessing Game 🎮

Project Description

This is a simple Number Guessing Game developed using Python. The computer generates a random number between 1 and 100, and the user has to guess the correct number.

Features

- Generates a random number between 1 and 100.
- Allows users to guess the number.
- Displays "Too High" or "Too Low" hints.
- Counts the total number of attempts.
- Allows users to play multiple rounds.

Technologies Used

- Python
- Random Module
- VS Code

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python guess.py

Project Structure

- "guess.py" – Main Python program.
- "README.md" – Project documentation.

Learning Outcomes
